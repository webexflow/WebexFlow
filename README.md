> **WEBSITES • APPS • AUTOMATION**

## 🚀 Overview

This repository contains the complete frontend agency website for **Webex_Flow** (Phase 1). It is built with a modern React + Vite + Tailwind CSS stack, featuring futuristic aesthetic detailing, custom glassmorphism, responsive navigation, and modular architecture.

## 📄 Pages Included

1. **Home (`/`)**
   - **Hero:** Interactive mockup composition with floating UI badges and responsive metrics
   - **Introduction:** 4 agency pillars (Creative Thinking, Modern Technology, Business-Focused Solutions, AI-Assisted Development)
   - **Services Overview:** 3 large service cards
   - **Featured Project:** Skin Atelier desktop & mobile mockups with live link
   - **Why Webex_Flow:** 6 core agency differentiators
   - **Our Process:** 5-step animated lifecycle (Discover, Strategize, Create, Test, Launch)
   - **FAQ:** 10 expandable interactive accordions
   - **Final CTA:** Direct contact & WhatsApp/Email options

2. **Services (`/services`)**
   - Detailed breakdowns for **Website Development**, **Application Development**, and **AI & Business Automation**
   - Key capabilities, offerings, and tangible business benefits
   - Project consultation CTA

3. **Our Work (`/work`)**
   - Confident showcase of completed client project: **Skin Atelier**
   - Scope overview, key deliverables, live project link
   - "More Digital Experiences Coming Soon" note (Phase 2 ready)

4. **About (`/about`)**
   - Origin story & "Why We Started"
   - Mission & Vision
   - 6-step methodical execution approach
   - AI-Assisted Development policy with human technical oversight

5. **Contact (`/contact`)**
   - Official direct email & Instagram channels
   - Frontend-only interactive enquiry form with validation (Name, Email, Phone, Service, Budget, Description)
   - Prepared summary preview & direct mail client launcher

## 💻 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### Build for Production
```bash
npm run build
```
The optimized bundle will be generated in `dist/`, ready for zero-configuration deployment to **Vercel** or **Netlify**.
